# TakTuk

> **Go anywhere. Get anything.**

Taktuk is a Sri Lankan ride-hailing and food delivery web app concept. Ride, Eats, and Drive — all in one app. Built as a modern, responsive, single-page-per-route experience using plain HTML, CSS, and vanilla JavaScript.

## ✨ Features

### 🚗 Ride (`ride.html`)
- Booking form with pickup and dropoff inputs
- **Live autocomplete** for 30+ Sri Lankan cities and towns
- **Live fare estimation** using the haversine formula
- Four ride tiers with different base rates and per-km pricing:
  - Taktuk Go — LKR 150 base · 85/km
  - Taktuk Premier — LKR 250 base · 130/km
  - Taktuk Tuk — LKR 100 base · 60/km
  - Taktuk Moto — LKR 80 base · 45/km
- Interactive map preview with route, pickup, and dropoff markers
- Popular route fare cards (Airport → Fort, Kandy → Colombo, etc.)

### 🍜 Eats (`eats.html`)
- Hero with delivery address search
- Category grid — Rice & Curry, Burgers, Pizza, Noodles, Healthy, Desserts
- Featured restaurant cards with ratings and delivery times
- App download CTA section

### 🧑‍✈️ Drive (`drive.html`)
- Driver signup form (name, phone, email, city, vehicle type, registration)
- Benefits grid — earnings, flexible hours, insurance, driver app
- Dark hero with driver statistics

### 🏠 Home (`index.html`)
- Hero with pickup/dropoff search and live fare preview
- Service grid — Ride, Eats, Bike, Business
- "How it works" section with animated phone mockup
- Stats bar — 10M+ rides, 150+ cities, 4.9★ rating, 24/7 support
- App download CTA with QR placeholder

### 🌍 Shared
- Responsive navigation with mobile hamburger menu
- Sign up / Log in modal
- Toast notification system
- Reusable button, form, and card components
- Accessible focus states and reduced-motion support
- Fully responsive from 320px up to large desktop
